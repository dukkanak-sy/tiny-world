# TINY WORLD

لعبة بقاء ثلاثية الأبعاد بمنظور الشخص الثالث: إنسان تقلّص إلى حجم صغير ويستكشف أرض الغابة.

## تشغيل المشروع محلياً
1. ثبّت Node.js (الإصدار 20 أو أحدث).
2. افتح مجلد المشروع في VS Code أو الطرفية.
3. نفّذ:
   ```bash
   npm install
   npm run dev
   ```
4. افتح العنوان المحلي الذي يظهر في الطرفية.

## التحكم
- `W A S D` أو الأسهم: الحركة
- `Space`: القفز
- `F`: الهجوم عندما تكون قريباً من العنكبوت

## النسخة الحالية
- مشهد غابة ثلاثي الأبعاد باستخدام Three.js.
- شخصية لاعب بمنظور الشخص الثالث.
- أشجار وعشب وفطر عملاق.
- موارد خشب وأوراق قابلة للجمع.
- عنكبوت يطارد اللاعب ويمكن مهاجمته.

## النشر على GitHub Pages
يمكن نشر نسخة البناء بعد `npm run build` باستخدام GitHub Actions أو خدمة استضافة ثابتة تدعم Vite.
